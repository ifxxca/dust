## Penerimaan dan cakupan

Setiap perubahan material memerlukan pasangan screenshot dengan viewport/zoom/role/dataset/state/theme sama. Perubahan asosiasi error juga memerlukan respons validasi dan fokus melalui interaksi. Dialog memerlukan keyboard Tab/Escape, focus return dan batas viewport. Keterbatasan native dan fitur nonaktif dicatat; tidak diganti evidence fiktif. Data produksi tidak dipakai untuk mutation. Commit terpisah menurut kelompok; tidak push.
