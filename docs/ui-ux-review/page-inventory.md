# Inventaris halaman

26 Oktober 2026 · baseline HEAD e3a0be0 + empat perubahan pengguna yang sudah ada

Audit mengikuti kebijakan **Task-first operational UI** di AGENTS.md dan kebijakan dalam permintaan pengguna; tidak membuat kebijakan baru. Referensi: [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md), ui-ux-pro-max (hasil pencarian tabel shadcn dan focus-not-obscured), primitive Radix shadcn yang sudah terpasang. Frekuensi adalah inferensi dari tugas/peran, bukan telemetry. Tidak ada skor UX numerik.

Ditemukan **58 surface tugas**: 46 pengalaman web dari 34 file halaman Inertia (termasuk fallback registrasi nonaktif dan 404), serta 12 surface native. Varian role/dashboard, screen operations, history, dan mode monitoring dicatat terpisah karena tugasnya berbeda. Endpoint JSON, unduhan, redirect settings, route framework dan modul native Segera Hadir bukan halaman terpisah. Tidak ada halaman yang dihilangkan karena tidak ada di sidebar.

## Routing dan navigasi

Router diperiksa melalui php artisan route:list --json, routes/web.php, routes/settings.php, routes/api.php, controller Inertia::render, FortifyServiceProvider dan bootstrap/app.php. Route operations memiliki whitelist role dan policy view/assignment; detail execute dirender sebagai pickup-wizard. Dashboard memilih OperationalOverview atau RoleDashboard. Handover list/detail/history menggunakan satu komponen. pickup-results membungkus dua workspace. errors/not-found dirender oleh exception responder. Self-registration tidak diaktifkan. User mengimplementasikan MustVerifyEmail; akun fixture sudah verified pada baseline umum; capture kondisional memakai akun sementara unverified dan dipulihkan setelah setiap fase.

Sidebar: AppSidebar/NavMain, jneNavigation/jneBreadcrumbs, NavUser/UserMenuContent. JNE exceptions/reconciliation/collections/evidence/refresh berada pada hubungan kontekstual halaman utama. Detail pickup, hasil, report AWB, settings/security dan appearance tetap diinventarisasi walaupun bukan item sidebar langsung. Native mempunyai BottomNavigation dan state lokal sendiri, bukan route Inertia.

## Hasil verifikasi akhir

Seluruh 58 surface diaudit individual; **31 surface diverifikasi membaik** (29 perubahan langsung dan 2 workflow tertanam), **27 sengaja tidak diubah**. Tidak menghitung semua halaman sebagai improved hanya karena primitive bersama berubah. 148 definisi route, 67 GET/HEAD, tersimpan di [router aktual](evidence/routes.json); endpoint data dan unduhan tidak disamakan dengan halaman.

Temuan tambahan dari quality gate: **B3 — navigasi mobile**. Pada 390px dan 320px, hidden tooltip masih terpasang dan Escape gagal menutup menu setelah traversal keyboard; tombol tutup tidak terlihat. Source: resources/js/components/ui/sidebar.tsx:194 dan :524. Tooltip kini hanya dipasang saat sidebar desktop berupa ikon; tombol tutup 44px terlihat; kedua ukuran lolos satu Escape dan focus return. [Bukti sebelum](evidence/before-sidebar.json) / [sesudah](evidence/after-sidebar.json).
