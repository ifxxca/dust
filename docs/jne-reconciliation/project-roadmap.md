## Execution boundaries

Ordinary technical fixes proceed without approval. A pending business answer does not block independent safe work. A milestone remains partial while an exit criterion is unverified. No rule will infer ownership from an account, code prefix, approximate name, matching date or quantity. No automatic import changes finalized POP/handover quantities. Existing manual decisions remain auditable and protected.

No new infrastructure, service, dependency, customer portal or generic abstraction is planned. Use existing report jobs/actions, Laravel queues, MySQL, private report disk, Node/Playwright and current pages/components. External operations are verified with local fixtures until a safe authorized operational acceptance run is arranged.
